\section{Region Generation Algorithm}

\subsection{Objective}

Create fixed-size ecosystem regions.

Region Size:

[
5km \times 5km
]

\subsection{Input}

Project Boundary Polygon

\subsection{Output}

Region Grid

\subsection{Algorithm}

\begin{enumerate}
\item Load boundary polygon.
\item Convert to projected CRS.
\item Generate square grid.
\item Clip to boundary.
\item Store centroid.
\item Assign region ID.
\end{enumerate}

Output:

\begin{verbatim}

AP_000001

AP_000002

AP_000003

\end{verbatim}
