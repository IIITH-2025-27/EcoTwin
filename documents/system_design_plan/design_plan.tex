\section{Introduction}

This document describes the technical architecture,
system components, database design,
data flow, APIs, deployment strategy,
and implementation details for EcoTwin.

EcoTwin is a geospatial ecosystem discovery
and analog forecasting platform.

The platform enables:

\begin{itemize}
\item Ecosystem discovery
\item Similarity search
\item Temporal ecosystem analysis
\item Analog-based forecasting
\item Automated report generation
\end{itemize}

\section{Region Architecture}

\subsection{Region Definition}

A region represents the smallest searchable
ecosystem unit.

Region size:

[
5km \times 5km
]

Area:

[
25km^2
]

\subsection{Reasoning}

Using a fixed grid provides:

\begin{itemize}
\item Fast indexing
\item Uniform ecosystem representation
\item Easy retrieval
\item Simple forecasting
\end{itemize}

\subsection{Region Structure}

\begin{verbatim}
Region ID

Center Latitude
Center Longitude

Bounding Box

Polygon Geometry

Area
\end{verbatim}

\section{Database Design}

\subsection{regions}

\begin{verbatim}
CREATE TABLE regions (

region_id UUID PRIMARY KEY,

center_lat DOUBLE PRECISION,

center_lon DOUBLE PRECISION,

area_km DOUBLE PRECISION,

geom GEOMETRY(POLYGON,4326),

created_at TIMESTAMP

);
\end{verbatim}

% ---------------------------------------------------------

\subsection{region_features}

\begin{verbatim}
CREATE TABLE region_features (

region_id UUID,

year INTEGER,

ndvi_mean REAL,
ndvi_std REAL,

ndwi_mean REAL,
ndwi_std REAL,

nbr_mean REAL,
nbr_std REAL,

dominant_ecosystem TEXT

);
\end{verbatim}

\begin{verbatim}
