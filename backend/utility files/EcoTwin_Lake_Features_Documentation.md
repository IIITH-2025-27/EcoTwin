# EcoTwin Lake Features Documentation

## Purpose
The `lake_features` table stores one row per **lake per year** containing ecological features extracted directly from the clipped Sentinel-2 image. It supports ecosystem similarity explanation, temporal analysis, and future forecasting. The table definition was introduced in migration 016 and later extended in migration 017. fileciteturn3file1L2-L19 fileciteturn3file0L18-L54

## Identity
- **id** – Primary key.
- **lake_id** – Foreign key to `lakes.lake_id`.
- **year** – Observation year.

## Processing
- **status** – pending, processing, completed, failed.
- **feature_version** – Version of the feature extraction pipeline.

## Pixel Quality
- pixel_count – Total clipped pixels.
- valid_pixel_count – Pixels used in computation.
- nodata_pixel_count – Masked/invalid pixels.
- coverage_percent – Valid pixel percentage.
- cloud_percent / masked_pixel_percentage – Masked pixel percentage.

## Sentinel-2 Band Statistics
For bands B2–B7:
- mean
- std
- min
- max
- median (added later)

These summarize reflectance for Blue, Green, Red and Red-Edge bands.

## Vegetation Indices
- NDVI (mean, std, min, max, median, p25, p75): vegetation health.
- EVI: dense vegetation.
- SAVI/MSAVI: vegetation with soil correction.
- GCI: chlorophyll proxy.
- NDRE: vegetation stress.

## Water Indices
- NDWI: surface water.
- MNDWI: enhanced water detection.
- NDMI: moisture.
- AWEI: automated water extraction.

## Burn / Soil
- NBR, NBR2: disturbance and burn.
- BSI: bare soil.
- NDBI: built-up influence.

## Texture (GLCM)
- Contrast
- Correlation
- Energy
- Entropy
- Homogeneity
- Dissimilarity

These describe spatial texture of the lake surface.

## Spectral Summary
- visible_brightness / brightness
- nir_red_difference / greenness
- green_swir_difference / wetness
- spectral_variance
- spectral_entropy

## Water Statistics
- water_area_sqkm
- water_pixels
- vegetation_pixels
- soil_pixels
- water_percentage
- vegetation_percentage
- soil_percentage
- valid_pixel_ratio
- masked_pixel_percentage
- water_to_land_ratio

## Metadata
- remarks
- error_message
- created_at
- updated_at

## Processing Workflow
1. Read merged Sentinel-2 image from `lake_images`.
2. Fetch lake polygon from `lakes.geom`.
3. Clip image to polygon.
4. Compute spectral bands.
5. Compute indices.
6. Compute texture metrics.
7. Compute water statistics.
8. Save one record into `lake_features`.

## Prithvi Relationship
The values in `lake_features` are calculated directly from Sentinel-2 imagery using raster processing and mathematical formulas. They are **not** generated by the Prithvi model. Prithvi embeddings are stored separately and are used for similarity search, while `lake_features` provides explainable ecological characteristics.
